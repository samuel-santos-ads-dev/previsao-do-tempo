# 🌤️ Previsão do Tempo

Aplicação web para consulta das condições meteorológicas de cidades, utilizando a API da [OpenWeatherMap](https://openweathermap.org/).

## 📌 Sobre o projeto

O projeto permite consultar informações meteorológicas de uma cidade, apresentando dados como temperatura atual, mínima e máxima, descrição das condições climáticas, umidade e ícone representativo do clima.

Desenvolvido como projeto de prática e aplicação dos conhecimentos em desenvolvimento web.

## 🚀 Funcionalidades

- Busca de informações meteorológicas por cidade.
- Exibição da temperatura atual.
- Exibição das temperaturas mínima e máxima.
- Descrição das condições climáticas em português.
- Apresentação da umidade do ar.
- Ícone correspondente às condições meteorológicas.
- Atualização automática do ano no rodapé.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
